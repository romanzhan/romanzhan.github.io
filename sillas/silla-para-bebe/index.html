Descripción

Silla infantil pensada para la seguridad del bebé y la comodidad del uso diario.

Tiene arnés de seguridad de tres puntos, respaldo alto y apoyabrazos que dan contención y ayudan a prevenir caídas. Las patas llevan una inclinación especial que da estabilidad y reduce el riesgo de vuelco, incluso si el chico se mueve o se hamaca.

El asiento tiene recortes ergonómicos para una mejor postura y suma apoyapiés. Incluye bandeja extraíble.

Se entrega desarmada. Si preferís recibirla armada, podés retirarla en nuestro domicilio de Villa Crespo, CABA.
